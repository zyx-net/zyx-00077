## 1. 产品概述

排班考勤异常对账分析工具是一款面向企业 HR 和考勤管理人员的专业分析工具，用于自动化识别和处理排班与打卡记录之间的异常差异，提供人工修正、规则配置和报告导出能力。

- 解决问题：传统人工核对考勤效率低、易出错，跨日班次、重复打卡等复杂场景难以处理
- 目标用户：企业 HR、考勤管理员、财务人员
- 核心价值：提高考勤核对效率 80% 以上，减少人工错误，提供可追溯的规则版本管理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 考勤管理员 | 本地应用登录 | 数据导入、规则配置、异常修正、报告导出、版本回滚 |
| HR 专员 | 本地应用登录 | 数据导入、异常查看、报告导出 |

### 2.2 功能模块

1. **数据导入模块**：排班表导入、打卡记录导入、调休配置导入、字段映射配置
2. **异常识别模块**：迟到识别、早退识别、缺卡识别、跨日班次处理、重复打卡识别、调休抵扣计算
3. **规则管理模块**：规则配置、版本历史、规则回滚、规则启用/禁用
4. **人工修正模块**：异常列表、单条修正、批量修正、修正备注
5. **统计分析模块**：异常汇总、员工维度统计、部门维度统计、时间维度趋势
6. **报告导出模块**：HTML 报告、Markdown 报告、Excel 导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 首页仪表盘 | 数据概览 | 批次管理、快速导入、异常统计概览、最近操作记录 |
| 数据导入页 | 导入模块 | 文件上传、字段映射预览、数据校验、错误提示、导入确认 |
| 异常分析页 | 异常识别+修正 | 异常列表、筛选过滤、单条/批量修正、异常详情查看 |
| 规则配置页 | 规则模块 | 规则列表、规则编辑、版本历史、回滚操作、规则开关 |
| 统计报告页 | 统计+导出 | 多维度统计图表、报告生成、格式选择、下载导出 |
| 批次管理页 | 持久化 | 批次列表、批次详情、数据查看、批次删除 |

## 3. 核心流程

### 3.1 主流程（验收路径）

用户导入排班表和打卡记录 → 系统自动进行字段映射和数据匹配 → 规则引擎识别各类异常 → 人工查看并修正异常 → 生成并导出对账报告

```mermaid
flowchart LR
    A["导入排班表"] --> B["导入打卡记录"]
    B --> C["导入调休配置"]
    C --> D["字段映射配置"]
    D --> E["数据匹配"]
    E --> F["规则引擎识别异常"]
    F --> G["异常列表展示"]
    G --> H["人工修正异常"]
    H --> I["生成统计分析"]
    I --> J["导出HTML/Markdown报告"]
```

### 3.2 失败路径（验收场景）

1. **缺员工编号列**：导入文件缺少必要字段时，系统提示错误并阻止导入
2. **错误时区配置**：时区配置错误导致打卡时间计算错误，系统提供时区校正功能
3. **夜班跨日打卡**：跨日班次自动识别，正确计算工作时长
4. **同窗口重复打卡**：短时间内多次打卡自动去重，保留有效记录

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝 #1e3a5f（专业、稳重），辅助色：橙色 #f97316（警示、异常标识），成功色：绿色 #10b981
- **按钮风格**：圆角 6px，微妙阴影，hover 状态有轻微放大和颜色加深
- **字体**：中文使用 PingFang SC，英文使用 Inter，等宽数据列使用 JetBrains Mono
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局，数据表格支持固定表头和虚拟滚动
- **图标风格**：使用 lucide-react 线性图标，异常状态使用带颜色背景的图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|---------|----------|---------|
| 首页仪表盘 | 数据概览 | 统计卡片（异常总数、待处理、已修正）、最近批次列表、快速操作区、异常分布环形图 |
| 数据导入页 | 导入模块 | 拖拽上传区、文件预览表格、字段映射下拉选择器、校验错误提示、导入进度条 |
| 异常分析页 | 异常识别+修正 | 筛选工具栏、异常数据表格（支持行内编辑）、修正侧边面板、异常类型标签 |
| 规则配置页 | 规则模块 | 规则卡片列表、版本时间线、回滚确认弹窗、规则开关切换 |
| 统计报告页 | 统计+导出 | 多标签图表区（柱状图、折线图、饼图）、报告格式选择器、预览区、下载按钮 |
| 批次管理页 | 持久化 | 批次列表表格、批次详情抽屉、数据对比视图、删除确认 |

### 4.3 响应式

- 桌面端优先设计（1280px 以上）
- 平板端（768px-1279px）：左侧导航收起为图标模式
- 移动端（<768px）：底部导航栏，表格支持横向滚动

## 5. 数据持久化设计

- **存储引擎**：浏览器 IndexedDB + localStorage 双重存储
- **持久化内容**：批次信息、原始导入数据、规则配置历史、人工修正记录
- **重启恢复**：应用启动时自动加载最近批次数据，所有历史数据可追溯
- **数据隔离**：按批次隔离数据，支持多批次并行处理
